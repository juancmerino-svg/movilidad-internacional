# Plantilla Word para RESU

La versión de envío usa `templates/resu-reference.docx` como `reference-doc` de Quarto. La plantilla debe mantener fuente Times New Roman 12 pt, interlineado sencillo y márgenes de 1 pulgada. El archivo binario se genera una sola vez y después queda versionado; no contiene resultados ni información identificable.
